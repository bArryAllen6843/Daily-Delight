# Daily Delight

Freshly cooked, homemade meals delivered to your workplace — with an exciting new menu every single day. Good food, the way home food should taste.

A marketing website for **Daily Delight by Soni**, showcasing the brand and the daily corporate meal menu. Built with React, Vite, and Tailwind CSS.

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:5173 to view it locally.

## Build

```bash
npm run build
```

## Configuration

Business details (name, Instagram handle, WhatsApp number) live in [`src/config.js`](src/config.js) — update the WhatsApp number there before going live.
